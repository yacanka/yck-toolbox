# Kaynak bildirimleri

Bu klasördeki lisans metinleri değiştirilmeden aşağıdaki PyPI kaynak dağıtımlarından alınmıştır:

- `openpyxl-3.1.5-LICENCE.rst`: `openpyxl==3.1.5` kaynak arşivi, `LICENCE.rst`.
- `et_xmlfile-2.0.0-LICENCE.rst` ve `et_xmlfile-2.0.0-LICENCE.python`:
  `et_xmlfile==2.0.0` kaynak arşivi, aynı adlı dosyalar.

İlgili wheel paketleri bu metinleri içermediği için dağıtıma ayrıca eklenir.
Diğer paketlerin lisansları `collect_licenses.py` tarafından kurulu wheel'lerden alınır.
